# 🎯 Quiz Game System

A console-based Quiz Game System developed in **C++** using **Object-Oriented Programming (OOP)** concepts. This project allows users to answer multiple-choice questions, calculates their score, and displays the final result.

---

## 📌 Features

- Interactive console-based interface
- Multiple-choice quiz questions
- Automatic answer validation
- Score calculation
- Percentage calculation
- Grade evaluation
- Modular OOP design

## 🎮 How to Play

1. Launch the application.
2. Select **Start Quiz**.
3. Read each question carefully.
4. Enter **A**, **B**, **C**, or **D**.
5. After all questions are completed, your score, percentage, and grade will be displayed.
